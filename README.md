# 💰 PennyPilot

### AI-Powered Personal Finance Management Platform

PennyPilot is a full-stack personal finance management application designed to help users track income and expenses, manage budgets and financial goals, analyze spending patterns, and receive personalized AI-powered financial insights.

The application combines a **React + Vite frontend**, **Spring Boot backend**, **PostgreSQL database**, **JWT authentication**, and **Google Gemini AI**.

---

## ✨ Features

### 🔐 Authentication

- User registration and login
- JWT-based authentication
- Protected dashboard routes
- Secure frontend-backend communication

### 💳 Transaction Management

- Add income and expense transactions
- Edit transactions
- Delete transactions
- Categorize transactions
- Track transaction dates and amounts
- Import transactions using external transaction IDs
- Prevent duplicate imported transactions
- Export transactions as CSV

### 📊 Financial Dashboard

- Total income
- Total expenses
- Net balance
- Budget overview
- Financial goals
- Recent transactions
- Spending visualizations
- AI-powered spending insights

### 💰 Budget Management

- Create category-based budgets
- Set spending limits
- Monitor spending progress
- Compare actual spending with budget limits
- Track budget utilization

### 🎯 Financial Goals

- Create savings goals
- Set target amounts
- Track saved amounts
- Monitor goal progress

### 📈 Analytics

- Income vs. expenses visualization
- Expense category analysis
- Savings rate
- Highest spending category
- Total transaction count
- Financial status overview
- Spending pattern analysis

### 🤖 AI-Powered Spending Insights

PennyPilot integrates **Google Gemini** to analyze transaction data and generate personalized financial insights.

The AI-powered system can identify:

- High-spending categories
- Unusual spending patterns
- Potential duplicate transactions
- Negative cash flow
- Areas where spending can be reduced
- Budgeting opportunities
- Personalized financial recommendations

### 📥 CSV Export

Users can export transaction information as a CSV file for:

- Personal records
- Financial analysis
- External spreadsheet analysis
- Data backup
